
# Portfolio

Portfolio made with React

## Installation local

Clone the project

```bash
  git clone https://github.com/Rob1Sim/Portfolio-react.git
```


```bash
  cd portfolio
```

Install dependences:
```bash
  npm install
```

Pour lancer le serveur 

```bash
  npm run dev
```


## 🛠 Skills
React, Javascript, HTML, SCSS
